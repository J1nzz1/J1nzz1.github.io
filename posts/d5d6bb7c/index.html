图片迁移

起因是打开博客的速度非常慢，且与将要打开的页面的图片数量呈正相关。因此我判断是加载图片的速度过于慢，导致了页面加载速度受到了拖累。

为了解决这个问题，考虑了本地图片和线上图床两个方案，其中线上图床又分为免费图床和付费图床两个方案。

目前采取的是线上图床-免费图床-聚合图床，显然已经不符合需求。我参考以下教程，尝试了自行搭建付费图床，采用了七牛云的云服务，顺便安装了 Typora 和 Picgo，打算使用 Typora+Picgo+七牛云的架构，实现编辑.md 文件时可以直接插入图片，使图片自动上传到七牛云的仓库。

参考如下：
PicGo–图床工具的简单学习
Typora 安装与配置
使用 PicGo 配置七牛云图床
七牛云配置阿里云域名详细过程记录
七牛云+PicGo 设置图床报错 StatusCodeError: 401
七牛云成功保存但无法显示和访问
七牛云图床配置 https

最终配置好了 Typora+Picgo+七牛云，但是又遇到了一个问题，即七牛云没有 SSL 证书，只能生成 http 链接，而浏览器在处理博客网页时会把其中的图片链接从 http 换成 https，导致无法正确显示图片。如果使用阿里云的免费 SSL 证书的话需要每三个月重新申请一次证书，很麻烦。找了半天都没能找到解决方法，最后还是选择使用长期运营的免费图床。

根据多方建议，SM.MS 图床是最优解，但是该图床现在已经暂停新用户注册，无法使用。求其次使用路过图床，据说也远比之前的聚合图床稳定快速。缺点是该图床每日限制上传八张图片，现有图片要花费很久才能全部迁移。

坏消息是迁移图片到新图床、置换文章中的 URL 非常麻烦，好消息是我的好习惯让我不用再重新一张一张找图片——每一张图片我都在本地留有备份且命名清晰。即使如此迁移图片也是个大工程:(
